# 从 H5 原型迁移

## 已迁移的设计

六区连通布局、三元素环境互动、武器与自愈探索门控、篝火、背包制作、装备效果、道具快捷栏、二段跳、首领与根脉捷径均保留。渲染、物理、UI、输入、音频和存档读写已用 Godot 原生 API 重做。

浏览器的 localStorage 不会自动出现在原生应用中。若要继续原旅程，先从原设备导出 `mosslight-v1` 的 JSON，再在原生版设置中选择「导入旧旅程 JSON」。

开发者可在原 H5 游戏的浏览器控制台读取：

```js
copy(localStorage.getItem('mosslight-v1'))
```

将复制的内容保存为 `.json` 文件后导入。`copy` 是部分浏览器开发者工具提供的便捷命令；没有该命令时直接读取该 localStorage 项并保存结果。

## 兼容规则

- `discoveryVersion=2` 的存档保留明确发现的短刃、火、冰、雷和回春。
- 更早存档的默认短刃/寒冰/自愈不作为探索证明，仍需在世界中拾取。
- 已打开书库荆棘、已激活矿井机关、已获得长弓及月孢遗物的证明会保留。
- 旧 `relic` 转为原生 `moonwing`，旧三个快捷道具槽也会保留。
- 原生版与 H5 使用不同存档位置，分别维护各自进度。

## 原生重构的变化

移动使用真实物理体，敌人具有明确的动作阶段；位置、速度和攻击窗口重新调校。临时冰桥不跨应用重启保存，重新施法可恢复通路。世界两岸保留寒冰残响，避免导入旧旅程后回头受阻。

本版本未增加自动云同步，也没有把 H5 页面打包为 WebView。

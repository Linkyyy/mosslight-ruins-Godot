# 架构与扩展

## 运行层级

`GameRoot` 是场景协调器，负责区域切换、镜头、输入入口、生命周期、暂停与复活。`World` 显式使用 PAUSABLE，物理角色、投射物、机关和特效会随暂停停下。HUD 与 Menu 使用 ALWAYS，暂停时仍可操作，角色展示仍会轻微呼吸。

没有嵌入网页或 JavaScript。运行场景完全由 Godot 节点构成，平台碰撞、角色运动和近战 Area2D 都在 Godot 物理世界中执行。

## 模块边界

- `GameData`：区域描述、初始布局、地图布局、物品、配方、奖励与探索目标。
- `RunState`：唯一的能力门控和背包入口。攻击、施法、装备、制作、快捷道具都复用这些规则，UI 不直接赠送能力。
- `SaveStore`：JSON 外壳存储原始 payload 字符串及其 SHA-256；先写临时文件，再保留上一代，最后原子重命名。读取失败时尝试备份。
- `Events`：通知、音效、命中特效与场景请求。战斗脚本不依赖某个菜单节点路径。
- `Controls`：键盘、手柄和触屏共用 InputMap。触屏保存 pointer → action 归属及每个动作的按压计数。
- `Audio`：在内存中生成原始 WAV 音色，播放端离线独立运行。

## 角色与战斗

`MossPlayer` 继承 CharacterBody2D，胶囊碰撞体以脚底为原点，重力、落地和平台接触由 `move_and_slide()` 处理。跳跃使用 0.12 秒离地宽容、0.14 秒按键缓冲及松键截断。二段跳需要月孢之翼。

近战生效窗口内读取 `Melee` Area2D 的重叠物理体，通过实例 ID 记录已命中对象。每次挥击独立清理命中集合，避免重复扣血。箭矢与法术对本帧位移做物理射线查询；炸弹对世界反弹并在引信到期时结算一次范围伤害。

`MossEnemy` 使用明确的巡逻、察觉、蓄力、攻击、恢复、硬直和死亡状态。首领复用基础受击、元素状态和死亡接口，扩展三种攻击模式。死亡只结算一次，击败记录保存为 `region_index` 对应的稳定 spawn ID。

`TravelerArt` 是原创程序化矢量角色表现，移动与碰撞独立。更换成 SpriteFrames、AnimationPlayer 或骨骼动画时，可保留玩家物理与战斗接口，替换 `_draw()` 表现层。

## 关卡编辑

六个区域场景已包含 `Geometry`、`Objects`、`Enemies` 原生节点。编辑平台的 `position` 与 `size`，或直接移动遗物、篝火与怪物即可改变该场景。平台、怪物和遗物支持编辑器预览。

`GameData.REGIONS` 中的布局是初始设计蓝图，也是地图中简化地形的依据。正常运行优先使用已经提交的场景节点，不会覆盖编辑器中的位置。要修改地图连线、区域描述、房间宽度和出入口，编辑 `GameData`；改动房间宽度时同步调整地形边界。

如果希望全部重新从蓝图生成场景，可以执行：

```sh
godot --headless --path . res://tools/bake_rooms.tscn
```

这个开发工具会覆盖六个区域的手工布局修改，不属于正常启动或构建步骤。先提交编辑结果，再有意使用它。

怪物的 `spawn_id` 应保持唯一；调整已有怪物的位置时保留 ID，新增怪物使用新的 ID，避免老存档误判击败状态。

## UI 与输入

所有菜单共用 `MenuScreen` 外壳，顶部图标、标题、关闭位置和背景统一。背包目录与详情、装备右栏、地图详情和指南说明各自滚动，主世界始终暂停。

HUD 按钮不接收键盘焦点，避免点击快捷栏后空格触发按钮而不是跳跃。菜单按钮保留 Godot 原生焦点导航；手柄 LB/RB 切换分类，A 确认。安卓/iOS 的安全区域会转换成逻辑坐标后应用到菜单及触屏操作。

`InputMap` 已写入 `project.godot`，可在编辑器修改。`Controls` 只补齐缺失的默认动作。需要将运行时默认映射重新写入项目时，可运行 `tools/configure_inputs.tscn`。

## 数据与存档

原生存档版本为 3。只有已发现能力才能使用，背包中的旧默认短刃数量不会绕过发现门控。奖励按机关 ID 幂等发放，制作先核对所有材料，再统一扣除。

测试使用单独 profile，任何测试场景不得对真实玩家存档执行 reset。导入数据经过白名单字段和边界归一化，存档校验只用于发现损坏，不提供反作弊或云同步。

## 后续制作方向

下一轮实机制作建议优先做实际动画素材、移动端 GPU/触控分析、更多敌人编排、空间音效与环境乐曲，以及游戏设置中的按键重绑定。正式商业发行还需要各平台设备验收、签名和发行资源制作。

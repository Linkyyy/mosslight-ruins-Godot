# 苔光遗境 · Mosslight / Godot

原生 Godot 2D 横版动作冒险工程，重构自 [Mosslight H5 原型](https://github.com/Linkyyy/mosslight-ruins-h5)。使用 Godot 场景、CharacterBody2D、Area2D、原生 Control 与 GDScript；运行不依赖浏览器、WebView、网页服务或 JavaScript。

**已验证引擎：Godot 4.6.3 Standard（GDScript），Compatibility 渲染器。**

这是可运行、可编辑的第一版原生重构，包含完整的六区探索与首领流程。原创矢量角色、场景、图标和合成音效已随工程提供；它仍需要正式美术制作、设备实测与发行打磨。

## 启动

```sh
git clone https://github.com/Linkyyy/mosslight-ruins-Godot.git
cd mosslight-ruins-Godot
godot --editor --path .
```

也可在 Godot 项目管理器导入 `project.godot`，等待资源导入后按 **F5**。主场景为 `scenes/main.tscn`，新旅程从苔息庭院启程。

直接原生运行：

```sh
godot --path .
```

无需 .NET、npm、插件或第三方脚本依赖。中文字体子集已内置，首次启动无需下载字体。

## 内容与升级

- **六个连通区域**：苔息庭院、沉水回廊、荆棘书库、鸣雷矿井、月孢洞窟、古树心室；主路、隐藏支路和胜利捷径。
- **探索能力**：短刃、长弓、火/冰/雷、自愈、二段跳均需探索获得；新档不赠送这些能力。
- **角色操作**：加速/减速、跳跃缓冲、离地宽容、松键控制跳高、二段跳、消耗灵息的短距离闪避冲刺。
- **战斗**：三段近战连击，独立前摇/生效/收招、单次挥击去重、箭矢与法术碰撞、击退、命中顿帧、可关闭的镜头震动、火花和伤害数字。
- **怪物与首领**：巡逻、察觉、蓄力、扑击/射击、恢复、受击硬直；根骸守卫具有冲锋、地面波和弹幕三种预警攻击，低生命时节奏加快。
- **元素互动**：火焰焚开荆棘并灼烧敌人；寒冰冻结敌人与水面，冰桥有倒计时并在到期前闪烁；雷电通过水面唤醒矿井机关并眩晕敌人。
- **背包与装备**：品质卡、浅色详情页、武器/护甲/灵物栏、角色展示、制作配方、三个可分配的快捷道具槽；装备属性实际影响战斗。
- **原生全屏菜单**：地图、背包、装备、手记、指南和设置共用同一外壳；地图支持迷雾、目标、拖动、缩放、定位与双指手势。
- **设备操作**：键盘、手柄、手机多指摇杆与动作按钮；横屏布局、安全区域边距、暂停时输入释放和失焦自动暂停。
- **存档**：设备本地原子写入、SHA-256 损坏校验、上一代备份恢复、能力/装备/机关/击败敌人持久化；支持导入旧 H5 JSON。
- **音画**：分层视差、环境微粒、随动作变化的角色矢量骨架、披风和脚步表现、原生合成音效及环境音乐，离线可运行。

## 操作

| 动作 | 键盘 | 手柄 |
| --- | --- | --- |
| 移动 | A / D 或 ← / → | 左摇杆 |
| 跳跃 / 二段跳 | 空格 / W / ↑ | A |
| 攻击 | J | X |
| 元素施法 | K | Y |
| 闪避冲刺 | Shift | B |
| 互动 / 篝火 | E | RB |
| 切换元素 | Q | LB |
| 切换武器 | 1 / 2 / Tab | 装备菜单 |
| 回春 | R | 方向上 |
| 快捷道具 | 3 / 4 / 5 | 背包菜单 |
| 地图 / 背包 / 装备 / 指南 | M / B / I / H | Back 打开地图，LB / RB 切换菜单 |
| 暂停 / 返回 | Esc | Start |
| 全屏 | F / F11 | 设置菜单 |

手机默认横屏：左侧摇杆移动，右侧图标为跳跃、攻击、施法、冲刺、互动；下方一排图标处理武器/元素/回春/道具。每根触摸手指独立管理，暂停、失焦与菜单切换会释放输入。在桌面设置中也可开启触屏控件预览。

## 探索路线

庭院篝火东侧找到短刃，上层平台取得火焰，旧路深处取得回春。庭院高处的拱门通向月孢洞窟，攀登可取得二段跳。回廊水池前有寒冰灵印，对岸有长弓；书库的荆棘需火焰打开；矿井水池西侧可发现雷电，让它通过水面唤醒灵石机关。最后在古树心室挑战根骸守卫。

## 工程结构

```text
project.godot                  引擎设置与原生 InputMap
export_presets.cfg             Linux / Windows / Android 预设
scenes/main.tscn               场景协调、世界、相机与原生 UI
scenes/actors/                 玩家、怪物、投射物
scenes/world/                  六个可编辑区域、平台与互动对象
scenes/ui/                     HUD 与全屏菜单
scripts/core/                 事件总线、进度、存档、输入、音频、设计数据
scripts/actors/               物理移动、战斗、状态机、角色矢量表现
scripts/world/                平台、水面、冰桥、机关与视差背景
scripts/ui/                   原生菜单、地图、背包、触屏与样式工具
scripts/effects/               有上限的粒子、命中环和伤害数字池
assets/                       原创 SVG 图标与已授权的中文字体子集
tests/                        Godot 引擎内回归场景
tools/                        验证和场景生成工具
docs/                         架构、导出和迁移说明
```

在编辑器中打开 `scenes/world/*.tscn` 可直接移动平台、遗物和怪物。可扩展的位置、数据来源与注意事项见 [架构说明](docs/ARCHITECTURE.md)。

## 验证

```sh
python3 tools/check.py
```

或直接运行测试场景：

```sh
godot --headless --editor --import
godot --headless --path . res://tests/runner.tscn -- --test-profile
```

`--test-profile` 强制把测试存档放进 `.user_test/profile/`，避免覆盖玩家旅程。测试场景缺少这个标记会拒绝运行。Godot 不在 PATH 时，给 `GODOT_BIN` 指定引擎可执行文件路径。

测试使用真实 SceneTree、物理碰撞和原生控件，覆盖能力门控、跑跳、连击、远程命中、炸弹、元素机关、装备、六区流程、菜单/横屏布局、多指输入、死亡恢复、旧档迁移和损坏存档恢复。

## 导出与当前边界

已提供 Linux、Windows、Android 原生导出预设，参见 [导出说明](docs/EXPORT.md)。发布二进制需要与引擎版本匹配的导出模板；Android 还需要本机 SDK/JDK 和签名配置，凭证不入库。

当前自动验收以 Godot 4.6.3 的 headless 原生运行和回归为准。手机/手柄实机体验、窗口中的实际画面、Windows 可执行文件、Android 安装包和 iOS 导出需要相应设备与工具链进一步验收。仓库不包含未经验证的 APK 或桌面安装包。
